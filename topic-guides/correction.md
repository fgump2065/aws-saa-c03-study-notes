## Known corrections and freshness checks for the study guides

Treat these as reminders to verify, not as substitutes for current AWS documentation. Recheck availability and changing limits whenever a question depends on them.

- **S3 Object Lock:** It can be enabled on an existing general-purpose bucket; versioning is required. It is not limited to bucket creation. [AWS docs](https://docs.aws.amazon.com/AmazonS3/latest/userguide/object-lock-configure.html)
- **S3 server access logs:** Delivery is best effort and may be delayed, duplicated, or incomplete; do not describe them as a complete audit record. [AWS docs](https://docs.aws.amazon.com/AmazonS3/latest/userguide/ServerLogs.html)
- **S3 Select:** It is no longer available to new customers; existing customers can continue using it. [AWS docs](https://docs.aws.amazon.com/AmazonS3/latest/userguide/selecting-content-from-objects.html)
- **S3 request performance:** S3 scales automatically. Per-prefix request figures are useful guidance, but higher rates may take time to ramp up; avoid implying that key randomization is always required. [AWS docs](https://docs.aws.amazon.com/AmazonS3/latest/userguide/optimizing-performance.html)
- **API Gateway timeouts:** 29 seconds is the default and remains the limit for edge-optimized REST APIs, but Regional and private REST API integration timeouts can be raised above 29 seconds, subject to quota trade-offs. [AWS docs](https://docs.aws.amazon.com/apigateway/latest/developerguide/api-gateway-execution-service-limits-table.html)
- **RDS Multi-AZ reads:** A Multi-AZ DB instance standby does not serve reads; a Multi-AZ DB cluster has two readable standby instances. Identify which deployment the question describes. [AWS docs](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/Concepts.MultiAZ.html)
- **FIPS 140-3 Level 3:** Standard AWS KMS keys use HSMs validated to FIPS 140-3 Level 3. Choose CloudHSM when the requirement calls for dedicated HSM control or customer custody, not solely because the question says Level 3. [KMS docs](https://docs.aws.amazon.com/kms/latest/developerguide/key-store-overview.html), [CloudHSM docs](https://docs.aws.amazon.com/cloudhsm/latest/userguide/fips-validation.html)
- **EventBridge schedules:** AWS recommends EventBridge Scheduler for new scheduled invocations; scheduled rules are a legacy feature. [AWS docs](https://docs.aws.amazon.com/eventbridge/latest/userguide/eb-create-rule-schedule.html)
- **IAM/S3 policy example:** `s3:ListBucket` requires the bucket ARN (for example, `arn:aws:s3:::example-bucket`); `s3:GetObject` requires an object ARN (for example, `arn:aws:s3:::example-bucket/*`). Use separate statements or resources.
- **Message payload limits (2026):** SQS supports up to 1 MiB; EventBridge event buses and asynchronous Lambda invocations support up to 1 MB; SNS supports up to 1 MiB when configured, with supported subscription types/limits. Do not use the former 256 KiB SQS limit. [SQS](https://aws.amazon.com/about-aws/whats-new/2025/08/amazon-sqs-max-payload-size-1mib/), [EventBridge and Lambda](https://aws.amazon.com/blogs/compute/more-room-to-build-serverless-services-now-support-payloads-up-to-1-mb/), [SNS](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-sns-1mib-support/)
- **Availability as of October 2026:** QLDB support ended July 31, 2025; Timestream for LiveAnalytics stopped accepting new customers June 20, 2025; Forecast is unavailable to new customers; Kendra stopped accepting new customers July 30, 2026; and Snowball Edge is available only to existing customers; Managed Blockchain will stop accepting new customers October 29, 2026, and support ends September 29, 2027. Verify current status and alternatives before recommending these services. [QLDB](https://docs.aws.amazon.com/qldb/latest/developerguide/getting-started-step-7.html), [Timestream](https://docs.aws.amazon.com/timestream/latest/developerguide/AmazonTimestreamForLiveAnalytics-availability-change.html), [Forecast](https://docs.aws.amazon.com/forecast/latest/dg/forecast.dg.pdf), [Kendra](https://docs.aws.amazon.com/kendra/latest/dg/kendra-availability-change.html), [Snowball](https://aws.amazon.com/snowball/faqs/)
